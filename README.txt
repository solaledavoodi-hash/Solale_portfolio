پورتفولیوی شخصی سلاله داودی
=============================

فایل‌ها:
- index.html : ساختار صفحه
- style.css  : استایل‌ها و طراحی واکنش‌گرا
- script.js  : منوی موبایل، انیمیشن ورود سکشن‌ها و فرم واتساپ

روش اجرا:
1. هر سه فایل را در یک پوشه نگه دارید.
2. فایل index.html را با مرورگر باز کنید.
3. برای توسعه، پوشه را در Visual Studio Code باز کنید و در صورت تمایل از افزونه Live Server استفاده کنید.

نکات:
- فونت Estedad از Google Fonts بارگذاری می‌شود؛ برای بارگذاری آن اینترنت لازم است.
- فرم سفارش بک‌اند و ذخیره‌سازی دیتابیس ندارد؛ اطلاعات را به شکل پیام آماده در واتساپ باز می‌کند و کاربر باید ارسال نهایی را انجام دهد.
- شماره واتساپ در script.js با فرمت بین‌المللی تنظیم شده است.
- نمونه‌کارهای فعلی کارت‌های نمایشی هستند و باید با تصاویر و توضیحات واقعی پروژه‌ها جایگزین شوند.
- برای انتشار عمومی، هاست و دامنه لازم است.
